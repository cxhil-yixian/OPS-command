## 1. 這是什麼

OPS-command 是一組管理 Linux 伺服器的小工具，全部收在一個<b>選單</b>裡。你可以用它：

- <b>換 SSH 連接埠</b>：換錯了會自動還原，不會把自己關在門外。
- <b>封鎖一直猜密碼的 IP</b>：封鎖之前會先檢查，不會封到你自己。
- <b>看誰在連你的伺服器</b>。
- <b>增加、刪除、更換 IP 與 DNS</b>：換 IP 時新舊兩個同時存在，你從新 IP 登入確認之後才拿掉舊的。
- <b>改時區、校正時間、裝常用軟體、換下載來源、測試效能</b>。

> [!TIP]
> 它最大的特色是<b>做任何事之前，都會先告訴你「接下來會改什麼」，等你按 <kbd>y</kbd> 才真的動手</b>。
> 看不懂畫面上的說明時，按 <kbd>Enter</kbd> 或 <kbd>n</kbd> 就會取消，什麼都不會改。

## 2. 開始之前

### 你需要

- 一台 Linux 伺服器，而且你能用 SSH 登入。
- <b>root 權限</b>（最高管理權限）。用一般帳號登入的話，先輸入下面這行切換成 root：

  ```bash
  sudo -i
  ```

- 伺服器能連上網路（要從 GitHub 下載工具）。

### 支援哪些系統

| 系統 | 能不能用 |
|---|---|
| CentOS 7.9、RHEL 7–10、Rocky Linux、AlmaLinux | ✅ 可以 |
| Ubuntu 18.04 – 24.04、Debian 9 – 12 | ✅ 可以 |
| Alpine Linux | ✅ 可以（只有「壓力測試」不能用） |
| openSUSE、Arch、Amazon Linux 等其他系統 | ❌ 不支援 |

<b>網路設定（<kbd>n</kbd>）</b>目前只能在 Ubuntu 22.04 / 24.04、Rocky Linux 9、CentOS 7 上修改，其他系統只能查看。

不知道自己的系統是哪一個？輸入這行就會顯示：

```bash
cat /etc/os-release
```

> [!WARNING]
> <b>第一次用請先在測試機試。</b> 有些功能只在部分系統上實際測過。用在正式的伺服器之前，先找一台不重要的機器跑一次。

## 3. 三步驟開始

<b>① 登入伺服器並切換成 root</b>

```bash
sudo -i
```

<b>② 複製下面這一行，貼上，按 <kbd>Enter</kbd></b>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/ops.sh)
```

出現錯誤的話（有些精簡系統沒有 bash），改用這行：

```bash
curl -fsSL https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/ops.sh | sh
```

<b>③ 看到選單，第一次先按 <kbd>d</kbd> 再按 <kbd>Enter</kbd></b>

<kbd>d</kbd> 是「環境自我診斷」，會告訴你這台機器缺什麼。缺東西的話，回到選單按 <kbd>i</kbd> 就會自動補裝。

> [!TIP]
> <b>操作方式都一樣：</b>輸入選項前面的數字或字母，按 <kbd>Enter</kbd>。
> 子選單裡按 <kbd>b</kbd> 回到上一層，主選單按 <kbd>q</kbd> 離開。

下次要再用，重新貼一次第 ② 步那行就好。工具會自動更新成最新版。

## 5. 使用案例

每個案例都寫了「什麼時候用」和「按哪些鍵」。<b>主選單 → b → t</b> 的意思是：先在主選單按 <kbd>b</kbd>，進去後再按 <kbd>t</kbd>。

### 案例 A：把 SSH 從 22 換到其他埠

*什麼時候用：預設的 22 埠每天都有大量機器人在猜密碼，換成別的號碼能擋掉大部分。*

> [!CAUTION]
> <b>雲端主機請先做這件事：</b>阿里雲、騰訊雲、AWS 這類雲端主機，要先到<b>雲端後台的「安全群組」</b>放行新的埠號，
> 否則換完會連不進來（還好會自動還原，但要等 10 分鐘）。

1. 主選單按 <kbd>2</kbd>。
2. 輸入新的埠號，例如 `58763`（建議在 10000 – 65535 之間挑一個）。
3. 問「看門狗時限」時直接按 <kbd>Enter</kbd>（10 分鐘）。
4. 畫面會列出接下來要改的東西，確認後輸入 <kbd>y</kbd>。之後會再問一次「確定要繼續嗎」，一樣輸入 <kbd>y</kbd>。
5. <b>不要關掉這個視窗！</b>另外開一個新的終端機，用新埠登入看看：

   ```bash
   ssh -p 58763 你的帳號@伺服器IP
   ```

6. - <b>登入成功</b> → 回到原本的視窗，按 <kbd>3</kbd>，再輸入 <kbd>y</kbd>。完成！
   - <b>登入失敗</b> → 什麼都不用做，10 分鐘後會自動還原成 22。等不及的話按 <kbd>4</kbd>，再輸入 <kbd>y</kbd>，立刻還原。

> [!TIP]
> <b>為什麼不會被鎖在門外？</b>換埠的過程中，新舊兩個埠同時開著，還有一個「看門狗」在計時。
> 10 分鐘內沒按 <kbd>3</kbd> 確認，它就把所有設定改回原樣。
>
> 有裝 fail2ban 的話，它保護的埠也會自動跟著換，不用另外處理。

### 案例 B：有人一直在猜我的密碼

*什麼時候用：伺服器變慢，或是登入時看到「上次失敗登入 1532 次」這類訊息。*

<b>第一步：看看是不是真的有人在猜</b>

1. 主選單按 <kbd>5</kbd>，按 <kbd>Enter</kbd>。畫面每秒更新，會顯示正在連線的人和失敗次數。
2. 看完按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 離開。

<b>第二步：開啟自動封鎖（只要做一次）</b>

1. 主選單按 <kbd>b</kbd> 進入封鎖管理。
2. 畫面說「還沒安裝 fail2ban」的話，先按 <kbd>i</kbd> 安裝。
3. 按 <kbd>e</kbd> 建立 SSH 的保護規則，輸入 <kbd>y</kbd>。
4. 按 <kbd>d</kbd> 檢查一次，確認沒有紅色的錯誤訊息。

完成後，預設規則是：<b>10 分鐘內密碼錯 5 次，就封鎖那個 IP 1 小時</b>。
之後想看封了誰，到 <b>主選單 → b → 7</b>（排行）或 <b>b → r</b>（完整報告）。

> [!WARNING]
> 開啟之前，建議先做[案例 D](#案例-d把自己的-ip-加進白名單)，把自己的 IP 加進白名單，免得自己打錯密碼被封。

### 案例 C：手動封鎖或解封一個 IP

*什麼時候用：發現某個 IP 很可疑想直接擋掉，或是同事被誤封了。*

| 想做什麼 | 按哪裡 | 接著 |
|---|---|---|
| 封鎖 | 主選單 → <kbd>b</kbd> → <kbd>2</kbd> | 輸入 IP；問封多久時輸入 `3600`（1 小時）或 `perm`（永久），直接 <kbd>Enter</kbd> 用預設值 |
| 解封 | 主選單 → <kbd>b</kbd> → <kbd>3</kbd> | 輸入 IP |
| 查這個 IP 有沒有被封 | 主選單 → <kbd>b</kbd> → <kbd>4</kbd> | 輸入 IP |
| 看目前封了哪些 | 主選單 → <kbd>b</kbd> → <kbd>1</kbd> | — |

一次可以輸入好幾個 IP，用空白隔開。也可以封整段網段，例如 `203.0.113.0/24`。

> [!TIP]
> 要封鎖的 IP 如果是你自己目前連線用的 IP，工具會直接擋下來，不會讓你封到自己。

### 案例 D：把自己的 IP 加進白名單

*什麼時候用：開啟自動封鎖之前。白名單裡的 IP 密碼打錯幾次都不會被封。*

1. 先查自己的 IP。按 <kbd>q</kbd> 離開選單，輸入下面這行，你登入那一行最後面括號裡的就是：

   ```bash
   who
   ```

   例如 `root  pts/0  2026-10-13 10:05 (198.51.100.7)`，你的 IP 就是 `198.51.100.7`。

2. 重新打開選單，主選單 → <kbd>b</kbd> → <kbd>5</kbd>（白名單：加入），輸入那個 IP，再輸入 <kbd>y</kbd>。

> [!WARNING]
> 加進白名單<b>不會</b>解除已經被封的狀態。如果已經被封了，要先用[案例 C](#案例-c手動封鎖或解封一個-ip) 解封。

### 案例 E：設定「失敗幾次就封鎖、封多久」

*什麼時候用：覺得預設的「10 分鐘內錯 5 次、封 1 小時」太鬆或太緊。*

1. 主選單 → <kbd>b</kbd> → <kbd>t</kbd>，畫面會先列出現在的設定。
2. 問要調整哪個時直接按 <kbd>Enter</kbd>（就是 SSH），問要做什麼時再按 <kbd>Enter</kbd>（修改）。
3. 接著依序回答三個問題，不想改的直接按 <kbd>Enter</kbd>：

   | 它問 | 意思 | 範例 |
   |---|---|---|
   | 失敗幾次就封鎖？ | 密碼錯幾次 | `5` |
   | 在多久之內累計？ | 多久內錯這麼多次才算 | `10m`（10 分鐘） |
   | 封鎖多久？ | 被封之後多久自動解除 | `1d`（1 天）、`perm`（永久） |

4. 畫面會列出「改之前 → 改之後」，確認後輸入 <kbd>y</kbd>。

時間的寫法：`m` 是分鐘、`h` 是小時、`d` 是天、`w` 是週。只寫數字就是秒。

想恢復原本的設定：同樣進到 <b>b → t</b>，問要做什麼時按 <kbd>2</kbd>（還原）。

> [!WARNING]
> 「錯 1 – 2 次就封」或「永久封鎖」很容易封到自己，工具會多問你一次。設定之前，請先做[案例 D](#案例-d把自己的-ip-加進白名單)。

### 案例 F：時間或時區不對

*什麼時候用：日誌上的時間跟實際差了 8 小時（時區錯），或是差了幾分鐘（時鐘不準）。*

<b>時區錯了（差整數小時）</b>

1. 主選單 → <kbd>t</kbd> → <kbd>1</kbd>。
2. 輸入城市關鍵字找時區，例如 `Taipei` 或 `Shanghai`。
3. 輸入找到的完整名稱，例如 `Asia/Taipei`，再確認。

<b>時鐘不準（差幾秒到幾分鐘）</b>

1. 主選單 → <kbd>t</kbd> → <kbd>3</kbd>（立刻校時一次）。問要向哪台校時，直接按 <kbd>Enter</kbd>。
2. 想讓它以後都自動校正，再按 <kbd>4</kbd>（啟用自動校時）。
3. 畫面說缺少 chrony 的話，先在時間選單按 <kbd>i</kbd> 安裝。

> [!TIP]
> 改時區不會改到真正的時間，只是換一種顯示方式，可以放心改。
> 手動改時鐘（<kbd>2</kbd>）就比較敏感，工具會先告訴你可能的影響。

### 案例 G：安裝常用工具

*什麼時候用：需要 docker、nginx、git 這類軟體，但不知道這台系統該怎麼裝。*

1. 主選單按 <kbd>a</kbd>，畫面會先列出哪些已經裝了。
2. 按軟體前面的數字，例如 <kbd>1</kbd> 是 docker、<kbd>7</kbd> 是 git。
3. 確認畫面上要跑的指令後，輸入 <kbd>y</kbd>。

想一次裝好幾個：按 <kbd>c</kbd>，輸入名稱並用空白隔開，例如 `nc mtr git`。

> [!WARNING]
> Ubuntu / Debian 裝 <b>nginx</b> 會立刻啟動並佔用 80 埠。如果這台已經有網站在跑，先不要裝。

### 案例 H：安裝軟體很慢（換國內下載來源）

*什麼時候用：伺服器在中國大陸，`yum` / `apt` 下載非常慢或一直失敗。*

1. 主選單按 <kbd>9</kbd>。
2. 依序回答問題。<b>看不懂的問題直接按 <kbd>Enter</kbd> 用預設值</b>。鏡像站可以選 <kbd>1</kbd>（阿里雲）。
3. 最後會列出完整指令，確認後輸入 <kbd>y</kbd>。

> [!TIP]
> 這個功能用的是 linuxmirrors.cn 提供的外部腳本，不是本專案寫的。執行前會自動備份原本的設定。

### 案例 I：測試機器效能

*什麼時候用：剛買的主機，想知道 CPU、記憶體、硬碟實際的表現。*

> [!CAUTION]
> <b>不要在正式環境跑。</b>壓力測試會把機器操到滿載，網站和服務都會變得非常慢。
> 記憶體和 SWAP 測試還可能讓系統強制關掉一些程式。

1. 主選單按 <kbd>s</kbd>。畫面說缺少工具的話，先按 <kbd>i</kbd> 安裝。
2. 新手建議從 <kbd>1</kbd>（CPU）或 <kbd>3</kbd>（硬碟）開始，每項預設跑 60 秒。
3. 跑完畫面會顯示摘要，完整報告存在當下所在目錄的 `logs/` 資料夾裡。

### 案例 J：增加或更換 IP

*什麼時候用：機房或雲端多給了這台一個 IP，要把它加上去；或是要把主要的 IP 換成另一個。*

> [!CAUTION]
> <b>IP 不能自己編。</b>要加或換的 IP，必須是機房或雲端<b>已經分配給這台</b>的，否則加上去也連不到，
> 還可能搶到別人的 IP。雲端主機要先在雲端後台把 IP 綁到這台。

進入 <b>主選單 → n</b>，上面會先列出這台的網卡、IP、閘道和 DNS。

<b>增加一個 IP</b>

1. 按 <kbd>1</kbd>，輸入要加的 IP，例如 `203.0.113.6`。跟現有 IP 同一個網段的話，不用寫 `/24` 這種前綴。
2. 問「加在哪張網卡」時直接按 <kbd>Enter</kbd>，讓它自己判斷。
3. 畫面會列出要改的東西，確認後輸入 <kbd>y</kbd>。
4. 確認連線都正常後，按 <kbd>c</kbd> 確認。<b>5 分鐘內沒按 <kbd>c</kbd>，剛加的 IP 會自動拿掉。</b>

<b>刪除一個 IP</b>：按 <kbd>2</kbd>，輸入 IP，輸入 <kbd>y</kbd>，再按 <kbd>c</kbd> 確認。你現在連線用的那個 IP 不能刪，要換請用下面的「更換」。

<b>更換 IP（包括你現在連線用的那個）</b>

1. 按 <kbd>3</kbd>，依序輸入舊 IP 和新 IP，確認後輸入 <kbd>y</kbd>。這時新舊兩個 IP 同時存在。
2. <b>不要關掉這個視窗！</b>另外開一個新的終端機，用<b>新 IP</b> 登入：

   ```bash
   ssh 你的帳號@新IP
   ```

   SSH 換過埠的話記得加 `-p 埠號`。

3. - <b>登入成功</b> → <b>在新視窗裡</b>切換成 root、打開選單，到 <b>n → c</b> 確認。舊 IP 會在這一步拿掉，舊視窗跟著斷線是正常的。
   - <b>登入失敗</b> → 什麼都不用做，5 分鐘後會自動還原。等不及的話在舊視窗按 <kbd>r</kbd>，立刻還原。

> [!TIP]
> <b>為什麼一定要從新 IP 確認？</b>能從新 IP 登入，才證明新 IP 真的通。在舊視窗按 <kbd>c</kbd> 會被拒絕，
> 免得你還沒試過就把舊 IP 拿掉。
>
> 沒確認就重開機也不怕：開機後一樣會倒數，時間到就自動還原。

### 案例 K：更換 DNS

*什麼時候用：伺服器查不到網址（`ping google.com` 說找不到主機），或想換成別家的 DNS，例如 `1.1.1.1`、`8.8.8.8`。*

1. 主選單按 <kbd>n</kbd>，畫面最上面的「DNS」那一行就是目前用的。
2. 依需要按：
   - <kbd>4</kbd> 增加：輸入 DNS 的 IP。問「放在最前面嗎」時，想優先用它就輸入 <kbd>y</kbd>，否則按 <kbd>Enter</kbd>。
   - <kbd>5</kbd> 刪除：輸入要拿掉的 DNS。最後一台不能刪。
   - <kbd>6</kbd> 替換：依序輸入舊的和新的，新的會放在舊的原本的位置。
3. 確認後輸入 <kbd>y</kbd>。

> [!TIP]
> 加入之前，工具會先向那台 DNS 查一次。查不到會警告並問你要不要繼續，看不懂就按 <kbd>Enter</kbd> 取消。
> 改完之後要是反而查不到網址，會自動改回原本的設定。改 DNS 不會讓 SSH 斷線，所以不需要按 <kbd>c</kbd>。

## 6. 出問題怎麼辦

### 畫面說「需要 root 權限」

先按 <kbd>q</kbd> 離開，輸入 `sudo -i` 切換成 root，再重新貼一次[開始指令](#3-三步驟開始)。

### 換了 SSH 埠，新埠連不進來

- 先確認雲端後台的「安全群組」有沒有放行新的埠。
- <b>不要關掉原本的視窗</b>，等 10 分鐘就會自動還原。也可以在原本的視窗按 <kbd>4</kbd>，再輸入 <kbd>y</kbd>，立刻還原。

### 換了 IP，新 IP 連不進來

- 先確認這個 IP 真的已經分配給這台（問機房，或看雲端後台）。
- <b>不要關掉原本的視窗</b>，等 5 分鐘就會自動還原。也可以在原本的視窗到 <b>n → r</b>，立刻還原。

### 畫面說 IP「不在設定裡」或「可能是 DHCP」

這台的 IP 是機房或雲端自動發的，不是寫在這台的設定檔裡，在這裡改了也沒用。請到雲端後台或請機房更換。

### 自己被封鎖了，連不進伺服器

1. 從雲端後台的<b>網頁主控台</b>（VNC / Console）登入。
2. 切換成 root，打開選單，到 <b>b → 3</b> 解封自己的 IP。
3. 再到 <b>b → 5</b> 把自己的 IP 加進白名單，以後就不會再被封。

沒辦法開選單的話，也可以直接輸入（把 IP 換成你自己的）：

```bash
fail2ban-client set sshd unbanip 你的IP
```

### 不知道哪裡出了問題

按 <kbd>d</kbd>（整台機器的檢查）或 <b>b → d</b>（封鎖功能的檢查）。
紅色的 `x` 是錯誤，黃色的 `!` 是提醒，後面通常會直接寫怎麼修正。

### 看到不懂的問題，不知道該不該按 y

<b>按 <kbd>Enter</kbd> 或 <kbd>n</kbd> 就好。</b>沒有輸入 <kbd>y</kbd>，什麼都不會改。

---

## 7. 四條安全守則

1. <b>換 SSH 埠或換 IP 時，舊視窗不要關。</b>它是你的退路。
2. <b>開啟自動封鎖之前，先把自己的 IP 加進白名單。</b>
3. <b>壓力測試只在測試機跑。</b>
4. <b>看不懂就不要按 y。</b>先按 <kbd>d</kbd> 檢查，或問懂的人。

## 8. 名詞小辭典

| 名詞 | 意思 |
|---|---|
| <b>SSH</b> | 遠端登入伺服器的方式。你用終端機連伺服器，用的就是 SSH。 |
| <b>埠（port）</b> | 伺服器上的「門牌號碼」。SSH 預設走 22 號門。 |
| <b>root</b> | Linux 的最高管理員帳號，改系統設定都要用它。 |
| <b>IP</b> | 網路上每台電腦的地址，例如 `203.0.113.5`。 |
| <b>網段</b> | 同一組 IP 的範圍。`203.0.113.5/24` 的意思是 `203.0.113.1` – `203.0.113.254` 都在同一個網段。 |
| <b>DNS</b> | 把網址（例如 `google.com`）翻成 IP 的服務。DNS 不通，伺服器就查不到任何網址。 |
| <b>fail2ban</b> | 自動封鎖的程式。發現某個 IP 一直猜錯密碼，就把它擋在門外一段時間。 |
| <b>白名單</b> | 永遠不會被封鎖的 IP 清單。 |
| <b>看門狗</b> | 換埠或換 IP 時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。 |
| <b>安全群組</b> | 雲端主機在雲端後台的防火牆，跟伺服器裡面的防火牆是兩回事，兩邊都要放行。 |
| <b>時區</b> | 時間的顯示方式。台北和上海是 UTC+8，所以設錯會差 8 小時。 |
| <b>鏡像（下載來源）</b> | 安裝軟體時從哪裡下載。換成離你近的來源，下載會變快。 |
