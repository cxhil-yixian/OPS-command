## 1. 這是什麼

OPS-command 的 Windows 工具，是一個<b>圖形面板</b>。你可以用它：

- <b>換遠端桌面（RDP）的 Port</b>：換錯了會自動還原，不會把自己關在門外。
- <b>查電腦最近有沒有出狀況</b>：打開就自動檢查，用燈號告訴你哪裡要注意、該怎麼做。
- <b>擋掉一直猜密碼的人</b>：同一個來源猜錯太多次就自動封鎖。
- <b>一次裝好常用軟體</b>：打勾就裝，下載來源由微軟官方的 winget 核對。
- <b>暫停 Windows 更新、校正時間、開關防火牆 Port、管理帳號、開 SSH</b>。

> [!TIP]
> 會改設定的按鈕，按下去會<b>先跳出視窗說明接下來要改什麼，等你按「是」才動手</b>。
> 看不懂時按「否」，什麼都不會改。每次改了什麼也都會記在「操作記錄」裡。

## 2. 開始之前

### 你需要

- 一台 Windows 10 或 Windows 11 電腦。
- 能連上網路（要從 GitHub 下載工具）。
- <b>不需要</b>先用系統管理員身分開啟。按到要改設定的按鈕時，工具會問你要不要提權，按「是」後跳出「使用者帳戶控制」視窗，再按「是」就好。

### 支援哪些版本

| Windows 版本 | 能不能用 |
|---|---|
| Windows 10 / 11 專業版、企業版 | ✅ 可以 |
| Windows 10 / 11 家用版 | ⚠️ 大部分可以，但<b>遠端桌面相關功能不能用</b>（家用版本身就不能被遠端桌面連入） |
| Windows Server 2019 / 2022 | ❔ 還沒測過 |
| Windows 7 / 8 及更舊 | ❌ 不支援 |

不知道自己是哪個版本？按 <kbd>Win</kbd> + <kbd>R</kbd>，輸入 `winver`，按 <kbd>Enter</kbd>。

> [!WARNING]
> <b>用在重要的電腦之前，先找一台不重要的試一次。</b>每個功能都在測試機上實際按過，
> 但你的環境可能不一樣。<b>換遠端桌面 Port</b> 尤其要先試，而且要有主控台可以救。

## 3. 三步驟開始

<b>① 打開 PowerShell</b>

在「開始」按鈕上按右鍵，選「<b>Windows PowerShell</b>」（Windows 11 是「<b>終端機</b>」）。用一般身分開就可以。

<b>② 複製下面兩行，貼上，按 <kbd>Enter</kbd></b>

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12
irm https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/WINDOWS/ops-win.ps1 | iex
```

在 PowerShell 視窗裡按滑鼠右鍵就是貼上。第一行是讓舊版 PowerShell 能連上 GitHub，不要省略。
下載完會先核對檔案有沒有被改過，看到「完成（SHA256 已核對）」就會跳出面板，PowerShell 視窗可以關掉。

<b>③ 面板出來後，先點左邊「檢查與紀錄」→「檢查系統現況」</b>

它只看不改，會列出這台電腦目前的遠端桌面 Port、Windows 更新、帳號鎖定等設定。

> [!TIP]
> <b>操作方式都一樣：</b>點左邊的分類展開，再點功能，會開一個新視窗。
> 視窗上方「目前狀態」是這台電腦現在的實際設定，下面是按鈕，最下面黑色區域是執行結果。

下次要再用，重新貼一次第 ② 步那兩行就好，每次都會下載最新版。有新版時，面板上方也會用黃字提醒你。

<sub>不方便用指令的話，也可以從 GitHub 下載整個 `WINDOWS` 資料夾，雙擊裡面的 `Win_Admin_Tool.bat`，進去之後完全一樣。</sub>

## 5. 使用案例

每個案例都寫了「什麼時候用」和「點哪裡」。<b>遠端桌面 RDP → 更換 RDP Port</b> 的意思是：先點左邊的「遠端桌面 RDP」展開，再點「更換 RDP Port」。

### 案例 A：看看這台電腦現在的設定

*什麼時候用：接手一台不熟的電腦，或改完設定想確認有沒有生效。*

1. <b>檢查與紀錄 → 檢查系統現況</b>。
2. 視窗會列出遠端桌面 Port、Windows 更新狀態、帳號鎖定、能不能被 ping，以及目前有哪些 Port 正在使用。
3. 要留存或傳給別人看，按「匯出成文字檔」。預設存在工具的資料夾（`%LOCALAPPDATA%\OPS-command`），存檔視窗裡也可以改存到桌面。

這個功能只看不改，一般身分就能用，可以放心按。

### 案例 B：把遠端桌面從 3389 換到其他 Port

*什麼時候用：遠端桌面直接開在網路上，每天都有大量機器人在猜密碼。換成別的號碼能擋掉大部分。*

> [!CAUTION]
> <b>開始前一定要確認這兩件事：</b>
>
> 1. <b>換 Port 時，你現在的遠端桌面連線一定會斷。</b>如果新 Port 連不上，要等看門狗時間到才會自動還原。
>    最好有<b>主控台</b>（雲端後台的網頁畫面、或能走到電腦前面）可以救。
> 2. <b>雲端主機要先到雲端後台的「安全群組」放行新 Port</b>，否則換完一定連不進來。

1. <b>遠端桌面 RDP → 更換 RDP Port</b>。
2. 「新的 Port」填新的號碼，例如 `53389`（建議在 10000 – 65535 之間挑一個）；「看門狗時限」維持 10 分鐘。
3. 按「更換 Port」，看完說明按「是」。
4. 問「現在重啟遠端桌面服務嗎？」時按「是」。<b>這時連線會斷掉，是正常的。</b>
5. 在你自己的電腦打開「遠端桌面連線」，電腦欄位輸入 `IP:新Port`，例如 `203.0.113.5:53389`，重新連進去。
6. - <b>連得上</b> → 剛才的視窗還開著，按「確認新 Port 可用」→「是」。問要不要移除舊 Port 的規則時也按「是」。完成！
   - <b>連不上</b> → 什麼都不用做，時間到會自動改回原本的 Port，再用原本的方式連回去就好。

> [!TIP]
> <b>為什麼不會被鎖在門外？</b>工具會先建一個「看門狗」排程。時限內沒有按「確認新 Port 可用」，
> 系統就會自動把 Port 改回原樣，就算你已經登出、斷線、面板關掉也一樣。

### 案例 C：遠端桌面出現「發生驗證錯誤」

*什麼時候用：連遠端桌面時跳出「發生驗證錯誤。要求的函數不受支援」，訊息裡提到 <b>CredSSP 加密 Oracle 修復</b>。*

1. 在<b>發起連線的那台電腦</b>（你自己的電腦）打開工具。
2. <b>遠端桌面 RDP → CredSSP 加密預示修復</b>，按「設為『易受攻擊』」，看完警告按「是」。
3. 重新開機後再連一次遠端桌面。

> [!WARNING]
> 這是把安全檢查放寬，讓你先連得上。<b>根本的解法是兩邊電腦都裝好 Windows 更新</b>。
> 更新完之後，回到同一個視窗按「還原為『尚未設定』」。

### 案例 D：電腦自己重開機、藍畫面，想知道原因

*什麼時候用：早上發現電腦重開過、程式一直當掉，或想知道誰登入過這台電腦。*

1. <b>檢查與紀錄 → 事件檢視器</b>。打開就會自動檢查最近 7 天，大約幾秒鐘。
2. 看卡片的顏色：

   | 卡片 | 意思 |
   |---|---|
   | ✔ 綠字「沒有異常」 | 這一類沒問題 |
   | ⚠ 黃底「N 筆需要注意」 | <b>點進去看</b> |
   | 灰字「需要管理員權限才看得到」 | 「登入與帳號」要提權才能看，點一下會問你要不要提權 |

3. 點黃色卡片，清單裡「這代表什麼」和「建議怎麼做」會用白話說明，需要注意的排在最前面。
4. 想看更早的紀錄，把上方「檢查範圍」改成「最近 30 天」。要給懂的人看，按「匯出 CSV」。

這裡只看不改，可以放心用。

### 案例 E：一直有人在猜遠端桌面的密碼

*什麼時候用：登入時常常出現「帳戶已被鎖定」，或事件檢視器「登入與帳號」一直有登入失敗。*

<b>已經被鎖住的帳號，等鎖定時間過了會自動解開</b>（Windows 預設通常是 10 分鐘），先等一下再登入。

一直被鎖，通常代表有人正在猜你的密碼。比起關掉帳號鎖定，更好的做法是<b>把猜密碼的來源擋掉</b>：

1. <b>帳號與安全 → RDP 暴力破解自動封鎖</b>。
2. 先按「試算（不封鎖）」看看目前的設定會擋到誰。
3. 確認「白名單」裡有<b>你自己連進來的 IP</b>（工具會自動加上目前連進來的來源）。
4. 按「啟用／套用設定」。跳出的視窗會列出白名單，<b>逐一看過</b>，有不認得的 IP 就先按「否」，把它從白名單拿掉再啟用。
5. 之後同一個 IP 在 10 分鐘內猜錯 5 次，就會被擋 60 分鐘（數字都可以改）。擋錯人時用「解封指定 IP」。

> [!CAUTION]
> <b>不要關掉帳號鎖定。</b>關掉等於「密碼可以無限次亂猜」。<b>帳號與安全 → 帳號鎖定防護</b> 建議維持 5–10 次。

### 案例 F：暫時不想讓 Windows 自動更新

*什麼時候用：正在跑重要的工作，不想被自動更新重開機打斷。*

1. 暫停：<b>系統與更新 → Windows 更新</b>，按「停止 Windows 更新」→「是」。
2. 恢復：同一個視窗按「還原 Windows 更新」，會照暫停前的設定恢復。

> [!WARNING]
> 暫停更新會讓電腦收不到安全修補，<b>忙完記得恢復</b>。畫面如果說「被系統改回來了」，重新開機後再按一次停止。

### 案例 G：時間或時區不對

*什麼時候用：右下角的時間差了幾分鐘，或差了好幾個小時。*

1. <b>系統與更新 → 時間與時區</b>。
2. 時間差幾分鐘 → 按「立即校時」。
3. 差了好幾個小時（時區錯）→ 在「時區」下拉選單選對的時區（台灣是 `(UTC+08:00) 台北`），按「套用時區」。

### 案例 H：開放防火牆 Port、讓別人能 ping 到

*什麼時候用：架了網站或服務，別人連不進來；或想讓監控系統能 ping 這台電腦。*

| 想做什麼 | 點哪裡 |
|---|---|
| 開放、查詢、關閉一個 Port | <b>網路與防火牆 → 防火牆 Port 管理</b> |
| 允許 / 拒絕被 ping | <b>網路與防火牆 → Ping (ICMP) 設定</b> |

> [!TIP]
> 「關閉」只會刪掉<b>這個工具建立的</b>規則，不會動到其他程式自己建的規則。雲端主機記得也要到安全群組放行。

### 案例 I：一次裝好常用軟體

*什麼時候用：剛拿到一台新電腦，要裝 7-Zip、Notepad++、Chrome 這些常用工具。*

1. <b>系統與更新 → 常用軟體安裝（winget）</b>。等「狀態」那欄讀完，已經裝了的會顯示版本、不能勾。
2. 在「安裝」欄勾選要裝的軟體，按「安裝勾選的軟體」→「是」。每個軟體可能要幾十秒到幾分鐘。
3. 清單裡沒有的，到「搜尋其他軟體」分頁輸入名稱搜尋，選一個按「安裝選取的軟體」。
   安裝前會跳出<b>發行者</b>，確認是你要的那一家再按「是」。

> [!TIP]
> 如果顯示「找不到 winget」，照畫面說明到 Microsoft Store 安裝或更新「應用程式安裝程式」，再按「重新偵測」。
> Wireshark 裝完還要另外到 npcap.com 手動裝 Npcap 才抓得到封包。

### 案例 J：開 SSH，當遠端桌面的備用門

*什麼時候用：只靠遠端桌面連這台電腦，萬一遠端桌面出問題就進不來了。多開一條 SSH 當備用。*

1. <b>網路與防火牆 → OpenSSH Server</b>。
2. 「SSH Port」填一個號碼（例如 `22222`），「預設殼層」選 PowerShell，按「啟用」→「是」。沒裝的話會自動安裝，要幾分鐘。
3. 在你自己的電腦用 `ssh 帳號@這台的IP -p 22222` 測試看看。

> [!TIP]
> SSH 已經在跑的時候<b>不能換 Port</b>（會讓 SSH 連線斷掉）。要換請先按「停用」再用新 Port 啟用。雲端主機一樣要到安全群組放行。

### 其他功能

| 想做什麼 | 點哪裡 | 注意 |
|---|---|---|
| 啟用 / 停用內建的 Administrator 帳號 | 帳號與安全 → 內建 Administrator 帳戶 | 啟用後記得設一個強密碼；停用自己正在用的帳號會特別警告 |
| 改某個帳號的密碼 | 帳號與安全 → 變更本機帳號密碼 | — |
| 只讓自己的 IP 連遠端桌面 | 遠端桌面 RDP → RDP 只允許指定來源 IP | 有看門狗；套用後要開一條新的遠端桌面連線確認。IP 會變的話不要用 |
| 看誰用遠端桌面登入過 | 遠端桌面 RDP → RDP 登入紀錄 | — |
| 讓同一個帳號可以開兩個遠端桌面 | 遠端桌面 RDP → RDP 多工作階段 | 專業版仍然只能同時一個人連；家用版不能用 |
| Microsoft Store 在背景一直吃資源 | 系統與更新 → Microsoft Store 自動更新 | 按「關閉自動更新」 |
| 裝了 VMware 開不了虛擬機 | 系統與更新 → Hyper-V／VMware 切換 | 按「VMware 優先」，要重開機 |
| 顯示副檔名、隱藏檔、長路徑、關快速啟動這類常改的設定 | 系統與更新 → 常用登錄檔設定 | 打勾後按「套用變更」；改之前自動備份，弄錯按「還原備份」 |
| 改這台電腦的 IP 或 DNS | 網路與防火牆 → IP / DNS 設定 | 改 IP 有看門狗，時限內沒確認會自動還原 |
| 一張網卡加很多個 IP | 網路與防火牆 → 批量新增 IP | 只能用在固定 IP 的網卡 |
| 看磁碟用了多少 | 磁碟管理 → 唯讀磁碟視覺化 | 只看不改 |
| 開機自動執行程式、定時關機 | 自動排程 → 開啟自動排程管理 | 只管理這個工具建立的排程 |
| 每 10 分鐘、每 30 分鐘跑一次腳本 | 自動排程 → 開啟自動排程管理 → 「定時執行腳本」→ 新增 | 執行時機選「每隔一段時間」，再選間隔與從幾點開始 |
| 看這台電腦有哪些排程、改時間、刪掉不要的 | 自動排程 → 開啟自動排程管理 → 「所有排程」分頁 | 失敗的會標紅、點兩下看詳細；改或刪之前自動備份，弄錯按「還原備份」 |
| 看這個工具改過什麼 | 檢查與紀錄 → 操作記錄 | — |
| 用完不想在這台電腦留下這個工具的東西 | 什麼都不用做：主面板右上角「關閉時清除本工具的檔案」預設已勾 | 關閉面板時刪掉工具下載的程式、紀錄、匯出的檔案、排程與登錄檔的備份，以及指令歷史裡那行一行指令；要保留就關之前取消勾選 |

> [!CAUTION]
> <b>磁碟管理的格式化和清除會永久刪掉資料。</b>「格式化磁碟區」和「清除整顆磁碟」沒有辦法復原。
> 工具會要你重複輸入代號、編號和 `ERASE` 確認，但只要選錯磁碟，資料就沒了。<b>不確定的話不要碰。</b>

## 6. 出問題怎麼辦

### 貼上指令後出現「無法建立 SSL/TLS 通道」

第一行沒有一起貼到。兩行要一起複製、一起貼上。

### 出現「下載的檔案和 SHA256SUMS 對不上，拒絕執行」

下載到的檔案跟官方的不一樣，可能是網路被代理或公司的入口網頁攔截，也可能是 GitHub 剛更新、快取還沒同步。
等幾分鐘再試；還是不行就換個網路，或從 GitHub 下載整個 `WINDOWS` 資料夾改用雙擊 `Win_Admin_Tool.bat`。

### 出現「因為這個系統上已停用指令碼執行」

改用另一種方式：從 GitHub 下載 `WINDOWS` 資料夾，雙擊 `Win_Admin_Tool.bat`。

### 按了要提權，按「是」之後沒反應

舊的面板會關掉，新的系統管理員面板會在幾秒後出現。如果都沒出現，關掉所有 PowerShell 視窗，
改成在「開始」按鈕上按右鍵，選「Windows PowerShell (系統管理員)」，再貼一次開始的兩行指令。

### 換了遠端桌面 Port，新 Port 連不進來

- 先確認雲端後台的「安全群組」有沒有放行新的 Port。
- 什麼都不用做，看門狗時間到會自動還原成原本的 Port。
- 有主控台的話，也可以從主控台進去，在「更換 RDP Port」視窗按「立即還原」。

### 跳出錯誤訊息

訊息裡會寫詳細內容存在哪個檔案（`%LOCALAPPDATA%\OPS-command\error.log`），把這個檔案給懂的人看。
「檢查與紀錄 → 操作記錄」視窗裡按「開啟資料夾」，就能直接打開這個資料夾。

### 不知道哪裡出了問題

先看<b>檢查與紀錄</b>裡的「檢查系統現況」和「事件檢視器」，這兩個都只看不改。

### 看到不懂的問題，不知道該不該按「是」

<b>按「否」就好。</b>沒有按「是」，什麼都不會改。

## 7. 四條安全守則

1. <b>換遠端桌面 Port 之前，先準備好主控台。</b>連線一定會斷，主控台是你的退路。
2. <b>雲端主機記得同時改安全群組。</b>電腦裡的防火牆放行了，外面不一定進得來。
3. <b>磁碟的格式化和清除，不確定就不要碰。</b>
4. <b>看不懂就按「否」。</b>先看「檢查系統現況」，或問懂的人。

## 8. 名詞小辭典

| 名詞 | 意思 |
|---|---|
| <b>遠端桌面（RDP）</b> | 從另一台電腦連進來操作這台電腦的功能。 |
| <b>Port</b> | 電腦上的「門牌號碼」。遠端桌面預設走 3389 號門。 |
| <b>PowerShell</b> | Windows 內建的指令視窗，用來下載並打開這個工具。 |
| <b>系統管理員 / 提權</b> | 改系統設定需要的權限。「提權」就是從一般身分換成系統管理員身分。 |
| <b>使用者帳戶控制（UAC）</b> | 要提權時跳出來、問你「是否允許變更」的那個視窗。 |
| <b>防火牆</b> | 決定哪些連線可以進出這台電腦的守門員。 |
| <b>安全群組</b> | 雲端主機在雲端後台的防火牆，跟電腦裡的防火牆是兩回事，兩邊都要放行。 |
| <b>主控台</b> | 不透過網路、直接操作電腦畫面的方式，例如雲端後台的網頁畫面，或走到電腦前面。 |
| <b>看門狗</b> | 換 Port、改 IP 時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。 |
| <b>事件紀錄</b> | Windows 自動寫下的系統日記，記錄了開關機、錯誤、登入等事情。 |
| <b>白名單</b> | 永遠不會被封鎖的 IP 清單。一定要有你自己的 IP。 |
| <b>winget</b> | 微軟官方的軟體安裝工具，會核對下載的安裝檔沒有被改過。 |
| <b>SSH</b> | 用指令連進電腦的方式，可以當遠端桌面壞掉時的備用門。 |
| <b>SHA256</b> | 檔案的「指紋」。檔案只要改了一個字，指紋就會不一樣，用來確認下載的檔案沒被動過。 |
