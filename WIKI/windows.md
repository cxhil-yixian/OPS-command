## 1. 這是什麼

OPS-command 的 Windows 工具，是一個用 PowerShell 做的<b>選單</b>。你可以用它：

- <b>換遠端桌面（RDP）的 Port</b>：換錯了會自動還原，不會把自己關在門外。
- <b>查電腦為什麼自己重開機、藍畫面、誰登入過</b>：用「症狀」找，不用懂事件代碼。
- <b>解決遠端桌面連不上的常見錯誤</b>。
- <b>暫停 Windows 更新、校正時間、開關防火牆 Port、管理帳號</b>。

> [!TIP]
> 會改設定的功能都會<b>先說明接下來要改什麼，等你輸入 <kbd>Y</kbd> 才動手</b>。
> 看不懂時輸入 <kbd>N</kbd> 或直接按 <kbd>Enter</kbd>，什麼都不會改。

## 2. 開始之前

### 你需要

- 一台 Windows 10 或 Windows 11 電腦。
- 能連上網路（要從 GitHub 下載工具）。
- <b>不需要</b>先用系統管理員身分開啟。要改設定時，工具會問你要不要提權，答 <kbd>Y</kbd> 後跳出「使用者帳戶控制」視窗，按「是」就好。

### 支援哪些版本

| Windows 版本 | 能不能用 |
|---|---|
| Windows 10 / 11 專業版、企業版 | ✅ 可以 |
| Windows 10 / 11 家用版 | ⚠️ 大部分可以，但<b>遠端桌面相關功能不能用</b>（家用版本身就不能被遠端桌面連入） |
| Windows 7 / 8 及更舊 | ❌ 不支援 |

不知道自己是哪個版本？按 <kbd>Win</kbd> + <kbd>R</kbd>，輸入 `winver`，按 <kbd>Enter</kbd>。

> [!WARNING]
> <b>第一次用請先在測試機試。</b>這個工具目前只有少數功能在真的電腦上測過。
> 用在重要的電腦之前，先找一台不重要的試一次。<b>換遠端桌面 Port</b> 尤其要先試。

## 3. 三步驟開始

<b>① 打開 PowerShell</b>

在「開始」按鈕上按右鍵，選「<b>Windows PowerShell</b>」（Windows 11 是「<b>終端機</b>」）。用一般身分開就可以。

<b>② 複製下面兩行，貼上，按 <kbd>Enter</kbd></b>

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12
irm https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/WINDOWS/ops-win.ps1 | iex
```

在 PowerShell 視窗裡按滑鼠右鍵就是貼上。第一行是讓舊版 PowerShell 能連上 GitHub，不要省略。

<b>③ 看到選單，第一次先按 <kbd>S</kbd> 再按 <kbd>Enter</kbd></b>

<kbd>S</kbd> 是「檢查現況」，只看不改，會列出這台電腦目前的遠端桌面 Port、Windows 更新、帳號鎖定等設定。

> [!TIP]
> <b>操作方式都一樣：</b>輸入選項前面的英文字母或數字，按 <kbd>Enter</kbd>。大小寫都可以。
> 子選單裡按 <kbd>0</kbd> 回到上一層，主選單按 <kbd>0</kbd> 離開。

下次要再用，重新貼一次第 ② 步那兩行就好，每次都會下載最新版。

<sub>不方便用指令的話，也可以從 GitHub 下載整個 `WINDOWS` 資料夾，雙擊裡面的 `Win_Admin_Tool.bat`，進去之後完全一樣。</sub>

## 5. 使用案例

每個案例都寫了「什麼時候用」和「按哪些鍵」。<b>主選單 → A → 1</b> 的意思是：先在主選單輸入 <kbd>A</kbd>，進去後再輸入 <kbd>1</kbd>，每次都按 <kbd>Enter</kbd>。

### 案例 A：看看這台電腦現在的設定

*什麼時候用：接手一台不熟的電腦，或改完設定想確認有沒有生效。*

1. 主選單輸入 <kbd>S</kbd>。
2. 畫面會列出遠端桌面 Port、Windows 更新狀態、帳號鎖定、能不能被 ping，以及目前有哪些 Port 正在使用。看完按 <kbd>Enter</kbd> 回主選單。

這個功能只看不改，一般身分就能用，可以放心按。

### 案例 B：把遠端桌面從 3389 換到其他 Port

*什麼時候用：遠端桌面直接開在網路上，每天都有大量機器人在猜密碼。換成別的號碼能擋掉大部分。*

> [!CAUTION]
> <b>開始前一定要確認這兩件事：</b>
>
> 1. <b>換 Port 時，你現在的遠端桌面連線一定會斷。</b>如果新 Port 連不上，要等 10 分鐘自動還原。
>    最好有<b>主控台</b>（雲端後台的網頁畫面、或能走到電腦前面）可以救。
> 2. <b>雲端主機要先到雲端後台的「安全群組」放行新 Port</b>，否則換完一定連不進來。

1. 主選單 → <kbd>A</kbd> → <kbd>1</kbd>。工具會問要不要提權，輸入 <kbd>Y</kbd>，在跳出的視窗按「是」，再到新視窗重新走一次 <b>A → 1</b>。
2. 輸入新的 Port，例如 `53389`（建議在 10000 – 65535 之間挑一個）。
3. 問「看門狗時限幾分鐘」時直接按 <kbd>Enter</kbd>（10 分鐘）。
4. 畫面會列出接下來要做的事，確認後輸入 <kbd>Y</kbd>。
5. 問「現在重啟 TermService?」時輸入 <kbd>Y</kbd>。<b>這時連線會斷掉，是正常的。</b>
6. 在你自己的電腦打開「遠端桌面連線」，電腦欄位輸入 `IP:新Port`，例如 `203.0.113.5:53389`，重新連進去。
7. - <b>連得上</b> → 打開工具，主選單 → <kbd>A</kbd> → <kbd>2</kbd>（確認新 Port 可用），輸入 <kbd>Y</kbd>。問要不要移除舊 Port 的規則時也輸入 <kbd>Y</kbd>。完成！
   - <b>連不上</b> → 什麼都不用做，10 分鐘後會自動還原成 3389，再用原本的方式連回去就好。

> [!TIP]
> <b>為什麼不會被鎖在門外？</b>工具會先建一個「看門狗」排程。10 分鐘內沒有到 <b>A → 2</b> 確認，
> 系統就會自動把 Port 改回原樣，就算你已經登出、斷線也一樣。

### 案例 C：遠端桌面出現「發生驗證錯誤」

*什麼時候用：連遠端桌面時跳出「發生驗證錯誤。要求的函數不受支援」，訊息裡提到 <b>CredSSP 加密 Oracle 修復</b>。*

1. 在<b>發起連線的那台電腦</b>（你自己的電腦）打開工具。
2. 主選單 → <kbd>A</kbd> → <kbd>5</kbd> → <kbd>1</kbd>，看完警告後輸入 <kbd>Y</kbd>。
3. 再連一次遠端桌面。

> [!WARNING]
> 這是把安全檢查放寬，讓你先連得上。<b>根本的解法是兩邊電腦都裝好 Windows 更新</b>。
> 更新完之後，回到 <b>A → 5 → 2</b> 還原。

### 案例 D：電腦自己重開機、藍畫面，想知道原因

*什麼時候用：早上發現電腦重開過、程式一直當掉，或想知道誰登入過這台電腦。*

1. 主選單輸入 <kbd>L</kbd>（事件檢視器）。
2. 選符合的症狀：

   | 按鍵 | 症狀 |
   |---|---|
   | <kbd>1</kbd> | 電腦自己關機或重開機（還會寫出是哪個程式要求的） |
   | <kbd>2</kbd> | 藍畫面、硬體錯誤 |
   | <kbd>3</kbd> | 硬碟有問題 |
   | <kbd>4</kbd> | 服務啟動失敗，或設定被人改掉 |
   | <kbd>5</kbd> | 程式當掉、沒有回應 |
   | <kbd>6</kbd> | 誰登入過、密碼打錯、帳號被鎖（要提權） |
   | <kbd>7</kbd> | Windows 更新失敗 |

3. 畫面會列出最近 7 天的紀錄。輸入紀錄前面的編號可以看詳細內容，<kbd>T</kbd> 可以改成看 24 小時或 30 天，<kbd>E</kbd> 可以存成 Excel 打得開的檔案（放在桌面）。

這裡只看不改，可以放心用。

### 案例 E：帳號一直因為密碼打錯被鎖住

*什麼時候用：登入時常常出現「帳戶已被鎖定」。*

<b>已經被鎖住的帳號，等鎖定時間過了會自動解開</b>（Windows 預設通常是 10 分鐘），先等一下再登入。

如果三不五時就被鎖，可以讓 Windows 不再因為打錯密碼而鎖帳號：

1. 主選單 → <kbd>B</kbd> → <kbd>1</kbd>（解除帳號密碼鎖定），看完警告後輸入 <kbd>Y</kbd>。
2. 問題解決之後，<b>一定要把保護開回來</b>。用系統管理員身分開 PowerShell，輸入：

   ```powershell
   net accounts /lockoutthreshold:5
   ```

> [!CAUTION]
> <b>關掉鎖定等於「密碼可以無限次亂猜」。</b>一直被鎖，通常代表有人正在猜你的密碼，關掉鎖定只會讓他更好猜。
> 根本的解法是只讓自己的 IP 連進來（用雲端的安全群組或防火牆限制來源），
> 或換遠端桌面 Port（[案例 B](#案例-b把遠端桌面從-3389-換到其他-port)）。

### 案例 F：暫時不想讓 Windows 自動更新

*什麼時候用：正在跑重要的工作，不想被自動更新重開機打斷。*

1. 暫停：主選單 → <kbd>C</kbd> → <kbd>1</kbd>，輸入 <kbd>Y</kbd>。
2. 恢復：主選單 → <kbd>C</kbd> → <kbd>2</kbd>。

> [!WARNING]
> 暫停更新會讓電腦收不到安全修補，<b>忙完記得恢復</b>。畫面如果說要重新開機才會生效，就重開機後再做一次。

### 案例 G：時間或時區不對

*什麼時候用：右下角的時間差了幾分鐘，或差了好幾個小時。*

1. 主選單 → <kbd>C</kbd> → <kbd>4</kbd>。
2. 選要做的事：
   - 時間差幾分鐘 → <kbd>1</kbd>（立即同步網路時間）。
   - 差了好幾個小時（時區錯）→ <kbd>3</kbd>（設為台北 UTC+8），其他時區選 <kbd>4</kbd> 用關鍵字搜尋，例如 `Tokyo`。

### 案例 H：開放防火牆 Port、讓別人能 ping 到

*什麼時候用：架了網站或服務，別人連不進來；或想讓監控系統能 ping 這台電腦。*

| 想做什麼 | 按哪裡 |
|---|---|
| 開放一個 Port | 主選單 → <kbd>D</kbd> → <kbd>2</kbd> → <kbd>1</kbd>，輸入 Port，再選 TCP / UDP / 兩者 |
| 查某個 Port 有沒有程式在用 | 主選單 → <kbd>D</kbd> → <kbd>2</kbd> → <kbd>2</kbd> |
| 關閉之前開的 Port | 主選單 → <kbd>D</kbd> → <kbd>2</kbd> → <kbd>3</kbd> |
| 允許 / 拒絕被 ping | 主選單 → <kbd>D</kbd> → <kbd>1</kbd> |

> [!TIP]
> 「關閉 Port」只會刪掉<b>這個工具建立的</b>規則，不會動到其他程式自己建的規則。雲端主機記得也要到安全群組放行。

### 其他功能

| 想做什麼 | 按哪裡 | 注意 |
|---|---|---|
| 啟用 / 停用內建的 Administrator 帳號 | <kbd>B</kbd> → <kbd>2</kbd> | 啟用後記得設一個強密碼 |
| 改某個帳號的密碼 | <kbd>B</kbd> → <kbd>3</kbd> | — |
| 看誰用遠端桌面登入過 | <kbd>A</kbd> → <kbd>6</kbd> | — |
| 讓同一個帳號可以開兩個遠端桌面 | <kbd>A</kbd> → <kbd>4</kbd> | 專業版仍然只能同時一個人連；家用版不能用 |
| Microsoft Store 在背景一直吃資源 | <kbd>C</kbd> → <kbd>3</kbd> → <kbd>1</kbd> | 關掉 Store 自動更新 |
| 裝了 VMware 開不了虛擬機 | <kbd>E</kbd> → <kbd>3</kbd> | 切成 VMware 優先，要重開機 |
| 一張網卡加很多個 IP | <kbd>D</kbd> → <kbd>3</kbd> | 設錯可能斷網，遠端操作要小心 |
| 看磁碟用了多少 | <kbd>F</kbd> → <kbd>1</kbd> | 只看不改 |

> [!CAUTION]
> <b>磁碟管理的格式化和清除會永久刪掉資料。</b><b>F → 3</b>（格式化）和 <b>F → 4</b>（清除整顆磁碟）沒有辦法復原。
> 工具會要你重複輸入好幾次確認，但只要輸入錯一個字母，資料就沒了。<b>不確定的話不要碰。</b>

## 6. 出問題怎麼辦

### 貼上指令後出現「無法建立 SSL/TLS 通道」

第一行沒有一起貼到。兩行要一起複製、一起貼上。

### 出現「因為這個系統上已停用指令碼執行」

改用另一種方式：從 GitHub 下載 `WINDOWS` 資料夾，雙擊 `Win_Admin_Tool.bat`。

### 畫面是亂碼

關掉視窗重新開一個 PowerShell 再試。還是亂碼的話，改用雙擊 `Win_Admin_Tool.bat` 的方式。

### 按了 Y 要提權，視窗閃一下就不見

先關掉所有 PowerShell 視窗，改成在「開始」按鈕上按右鍵，選「Windows PowerShell (系統管理員)」，再貼一次開始的兩行指令。

### 換了遠端桌面 Port，新 Port 連不進來

- 先確認雲端後台的「安全群組」有沒有放行新的 Port。
- 什麼都不用做，10 分鐘後會自動還原成原本的 Port。
- 有主控台的話，也可以從主控台進去，主選單 → <kbd>A</kbd> → <kbd>3</kbd> 立刻還原。

### 不知道哪裡出了問題

按 <kbd>S</kbd> 看現況，或按 <kbd>L</kbd> 查事件紀錄。這兩個都只看不改。

### 看到不懂的問題，不知道該不該按 Y

<b>輸入 <kbd>N</kbd> 或直接按 <kbd>Enter</kbd> 就好。</b>沒有輸入 <kbd>Y</kbd>，什麼都不會改。

---

## 7. 四條安全守則

1. <b>換遠端桌面 Port 之前，先準備好主控台。</b>連線一定會斷，主控台是你的退路。
2. <b>雲端主機記得同時改安全群組。</b>電腦裡的防火牆放行了，外面不一定進得來。
3. <b>磁碟的格式化和清除，不確定就不要碰。</b>
4. <b>看不懂就不要按 Y。</b>先按 <kbd>S</kbd> 看現況，或問懂的人。

## 8. 名詞小辭典

| 名詞 | 意思 |
|---|---|
| <b>遠端桌面（RDP）</b> | 從另一台電腦連進來操作這台電腦的功能。 |
| <b>Port</b> | 電腦上的「門牌號碼」。遠端桌面預設走 3389 號門。 |
| <b>PowerShell</b> | Windows 內建的指令視窗，這個工具就是在裡面執行。 |
| <b>系統管理員 / 提權</b> | 改系統設定需要的權限。「提權」就是從一般身分換成系統管理員身分。 |
| <b>使用者帳戶控制（UAC）</b> | 要提權時跳出來、問你「是否允許變更」的那個視窗。 |
| <b>防火牆</b> | 決定哪些連線可以進出這台電腦的守門員。 |
| <b>安全群組</b> | 雲端主機在雲端後台的防火牆，跟電腦裡的防火牆是兩回事，兩邊都要放行。 |
| <b>主控台</b> | 不透過網路、直接操作電腦畫面的方式，例如雲端後台的網頁畫面，或走到電腦前面。 |
| <b>看門狗</b> | 換 Port 時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。 |
| <b>事件紀錄</b> | Windows 自動寫下的系統日記，記錄了開關機、錯誤、登入等事情。 |
