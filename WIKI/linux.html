Linux 新手指南

不用背指令，照著選單按數字或英文字母就能管理伺服器。這份指南教你怎麼開始，以及常見情況該按哪個鍵。

1這是什麼

OPS-command 是一組管理 Linux 伺服器的小工具，全部收在一個選單裡。你可以用它：

  • 換 SSH 連接埠：換錯了會自動還原，不會把自己關在門外。
  • 封鎖一直猜密碼的 IP：封鎖之前會先檢查，不會封到你自己。
  • 看誰在連你的伺服器。
  • 改時區、校正時間、裝常用軟體、換下載來源、測試效能。

它最大的特色是做任何事之前，都會先告訴你「接下來會改什麼」，等你按 y 才真的動手。看不懂畫面上的說明時，按 Enter 或 n 就會取消，什麼都不會改。

2開始之前

你需要

  • 一台 Linux 伺服器，而且你能用 SSH 登入。
  • root 權限（最高管理權限）。用一般帳號登入的話，先輸入下面這行切換成 root：
sudo -i
  • 伺服器能連上網路（要從 GitHub 下載工具）。

支援哪些系統

系統能不能用
CentOS 7.9、RHEL 7–10、Rocky Linux、AlmaLinux✅ 可以
Ubuntu 18.04 – 24.04、Debian 9 – 12✅ 可以
Alpine Linux✅ 可以（只有「壓力測試」不能用）
openSUSE、Arch、Amazon Linux 等其他系統❌ 不支援

不知道自己的系統是哪一個？輸入這行就會顯示：

cat /etc/os-release
⚠️ 第一次用請先在測試機試

有些功能只在部分系統上實際測過。用在正式的伺服器之前，先找一台不重要的機器跑一次。

3三步驟開始

  1. 登入伺服器並切換成 root 
    sudo -i
  2. 複製下面這一行，貼上，按 Enter 
    bash <(curl -fsSL https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/ops.sh)

    出現錯誤的話（有些精簡系統沒有 bash），改用這行：

    curl -fsSL https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/ops.sh | sh
  3. 看到選單，第一次先按 d 再按 Enter

    d 是「環境自我診斷」，會告訴你這台機器缺什麼。缺東西的話，回到選單按 i 就會自動補裝。

操作方式都一樣：輸入選項前面的數字或字母，按 Enter。子選單裡按 b 回到上一層，主選單按 q 離開。

下次要再用，重新貼一次第 2 步那行就好。工具會自動更新成最新版。

5使用案例

每個案例都寫了「什麼時候用」和「按哪些鍵」。主選單 → b → t 的意思是：先在主選單按 b，進去後再按 t。

案例 A：把 SSH 從 22 換到其他埠

什麼時候用：預設的 22 埠每天都有大量機器人在猜密碼，換成別的號碼能擋掉大部分。

⛔ 雲端主機請先做這件事

阿里雲、騰訊雲、AWS 這類雲端主機，要先到雲端後台的「安全群組」放行新的埠號，否則換完會連不進來（還好會自動還原，但要等 10 分鐘）。

  1. 主選單按 2。
  2. 輸入新的埠號，例如 58763（建議在 10000 – 65535 之間挑一個）。
  3. 問「看門狗時限」時直接按 Enter（10 分鐘）。
  4. 畫面會列出接下來要改的東西，確認後輸入 y。之後會再問一次「確定要繼續嗎」，一樣輸入 y。
  5. 不要關掉這個視窗！另外開一個新的終端機，用新埠登入看看： 
    ssh -p 58763 你的帳號@伺服器IP
  6. 登入成功 → 回到原本的視窗，按 3，再輸入 y。完成！
    登入失敗 → 什麼都不用做，10 分鐘後會自動還原成 22。等不及的話按 4，再輸入 y，立刻還原。

為什麼不會被鎖在門外？換埠的過程中，新舊兩個埠同時開著，還有一個「看門狗」在計時。10 分鐘內沒按 3 確認，它就把所有設定改回原樣。

有裝 fail2ban 的話，它保護的埠也會自動跟著換，不用另外處理。

案例 B：有人一直在猜我的密碼

什麼時候用：伺服器變慢，或是登入時看到「上次失敗登入 1532 次」這類訊息。

第一步：看看是不是真的有人在猜

  1. 主選單按 5，按 Enter。畫面每秒更新，會顯示正在連線的人和失敗次數。
  2. 看完按 Ctrl + C 離開。

第二步：開啟自動封鎖（只要做一次）

  1. 主選單按 b 進入封鎖管理。
  2. 畫面說「還沒安裝 fail2ban」的話，先按 i 安裝。
  3. 按 e 建立 SSH 的保護規則，輸入 y。
  4. 按 d 檢查一次，確認沒有紅色的錯誤訊息。

完成後，預設規則是：10 分鐘內密碼錯 5 次，就封鎖那個 IP 1 小時。之後想看封了誰，到 主選單 → b → 7（排行）或 b → r（完整報告）。

開啟之前，建議先做 案例 D，把自己的 IP 加進白名單，免得自己打錯密碼被封。

案例 C：手動封鎖或解封一個 IP

什麼時候用：發現某個 IP 很可疑想直接擋掉，或是同事被誤封了。

想做什麼按哪裡接著
封鎖主選單 → b → 2輸入 IP；問封多久時輸入 3600（1 小時）或 perm（永久），直接 Enter 用預設值
解封主選單 → b → 3輸入 IP
查這個 IP 有沒有被封主選單 → b → 4輸入 IP
看目前封了哪些主選單 → b → 1—

一次可以輸入好幾個 IP，用空白隔開。也可以封整段網段，例如 203.0.113.0/24。

要封鎖的 IP 如果是你自己目前連線用的 IP，工具會直接擋下來，不會讓你封到自己。

案例 D：把自己的 IP 加進白名單

什麼時候用：開啟自動封鎖之前。白名單裡的 IP 密碼打錯幾次都不會被封。

  1. 先查自己的 IP。按 q 離開選單，輸入下面這行，你登入那一行最後面括號裡的就是： 
    who

    例如 root pts/0 2026-10-13 10:05 (198.51.100.7)，你的 IP 就是 198.51.100.7。

  2. 重新打開選單，主選單 → b → 5（白名單：加入），輸入那個 IP，再輸入 y。

加進白名單不會解除已經被封的狀態。如果已經被封了，要先用 案例 C 解封。

案例 E：設定「失敗幾次就封鎖、封多久」

什麼時候用：覺得預設的「10 分鐘內錯 5 次、封 1 小時」太鬆或太緊。

  1. 主選單 → b → t，畫面會先列出現在的設定。
  2. 問要調整哪個時直接按 Enter（就是 SSH），問要做什麼時再按 Enter（修改）。
  3. 接著依序回答三個問題，不想改的直接按 Enter：
    它問意思範例
    失敗幾次就封鎖？密碼錯幾次5
    在多久之內累計？多久內錯這麼多次才算10m（10 分鐘）
    封鎖多久？被封之後多久自動解除1d（1 天）、perm（永久）
  4. 畫面會列出「改之前 → 改之後」，確認後輸入 y。

時間的寫法：m 是分鐘、h 是小時、d 是天、w 是週。只寫數字就是秒。

想恢復原本的設定：同樣進到 b → t，問要做什麼時按 2（還原）。

「錯 1 – 2 次就封」或「永久封鎖」很容易封到自己，工具會多問你一次。設定之前，請先做 案例 D。

案例 F：時間或時區不對

什麼時候用：日誌上的時間跟實際差了 8 小時（時區錯），或是差了幾分鐘（時鐘不準）。

時區錯了（差整數小時）

  1. 主選單 → t → 1。
  2. 輸入城市關鍵字找時區，例如 Taipei 或 Shanghai。
  3. 輸入找到的完整名稱，例如 Asia/Taipei，再確認。

時鐘不準（差幾秒到幾分鐘）

  1. 主選單 → t → 3（立刻校時一次）。問要向哪台校時，直接按 Enter。
  2. 想讓它以後都自動校正，再按 4（啟用自動校時）。
  3. 畫面說缺少 chrony 的話，先在時間選單按 i 安裝。

改時區不會改到真正的時間，只是換一種顯示方式，可以放心改。手動改時鐘（2）就比較敏感，工具會先告訴你可能的影響。

案例 G：安裝常用工具

什麼時候用：需要 docker、nginx、git 這類軟體，但不知道這台系統該怎麼裝。

  1. 主選單按 a，畫面會先列出哪些已經裝了。
  2. 按軟體前面的數字，例如 1 是 docker、7 是 git。
  3. 確認畫面上要跑的指令後，輸入 y。

想一次裝好幾個：按 c，輸入名稱並用空白隔開，例如 nc mtr git。

Ubuntu / Debian 裝 nginx 會立刻啟動並佔用 80 埠。如果這台已經有網站在跑，先不要裝。

案例 H：安裝軟體很慢（換國內下載來源）

什麼時候用：伺服器在中國大陸，yum / apt 下載非常慢或一直失敗。

  1. 主選單按 9。
  2. 依序回答問題。看不懂的問題直接按 Enter 用預設值。鏡像站可以選 1（阿里雲）。
  3. 最後會列出完整指令，確認後輸入 y。

這個功能用的是 linuxmirrors.cn 提供的外部腳本，不是本專案寫的。執行前會自動備份原本的設定。

案例 I：測試機器效能

什麼時候用：剛買的主機，想知道 CPU、記憶體、硬碟實際的表現。

⛔ 不要在正式環境跑

壓力測試會把機器操到滿載，網站和服務都會變得非常慢。記憶體和 SWAP 測試還可能讓系統強制關掉一些程式。

  1. 主選單按 s。畫面說缺少工具的話，先按 i 安裝。
  2. 新手建議從 1（CPU）或 3（硬碟）開始，每項預設跑 60 秒。
  3. 跑完畫面會顯示摘要，完整報告存在當下所在目錄的 logs/ 資料夾裡。

6出問題怎麼辦

畫面說「需要 root 權限」

先按 q 離開，輸入 sudo -i 切換成 root，再重新貼一次開始指令。

換了 SSH 埠，新埠連不進來

  • 先確認雲端後台的「安全群組」有沒有放行新的埠。
  • 不要關掉原本的視窗，等 10 分鐘就會自動還原。也可以在原本的視窗按 4，再輸入 y，立刻還原。

自己被封鎖了，連不進伺服器

  1. 從雲端後台的網頁主控台（VNC / Console）登入。
  2. 切換成 root，打開選單，到 b → 3 解封自己的 IP。
  3. 再到 b → 5 把自己的 IP 加進白名單，以後就不會再被封。

沒辦法開選單的話，也可以直接輸入（把 IP 換成你自己的）：

fail2ban-client set sshd unbanip 你的IP

不知道哪裡出了問題

按 d（整台機器的檢查）或 b → d（封鎖功能的檢查）。紅色的 x 是錯誤，黃色的 ! 是提醒，後面通常會直接寫怎麼修正。

看到不懂的問題，不知道該不該按 y

按 Enter 或 n 就好。沒有輸入 y，什麼都不會改。

7四條安全守則

  1. 換 SSH 埠時，舊視窗不要關。它是你的退路。
  2. 開啟自動封鎖之前，先把自己的 IP 加進白名單。
  3. 壓力測試只在測試機跑。
  4. 看不懂就不要按 y。先按 d 檢查，或問懂的人。

8名詞小辭典

SSH
遠端登入伺服器的方式。你用終端機連伺服器，用的就是 SSH。
埠（port）
伺服器上的「門牌號碼」。SSH 預設走 22 號門。
root
Linux 的最高管理員帳號，改系統設定都要用它。
IP
網路上每台電腦的地址，例如 203.0.113.5。
fail2ban
自動封鎖的程式。發現某個 IP 一直猜錯密碼，就把它擋在門外一段時間。
白名單
永遠不會被封鎖的 IP 清單。
看門狗
換埠時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。
安全群組
雲端主機在雲端後台的防火牆，跟伺服器裡面的防火牆是兩回事，兩邊都要放行。
時區
時間的顯示方式。台北和上海是 UTC+8，所以設錯會差 8 小時。
鏡像（下載來源）
安裝軟體時從哪裡下載。換成離你近的來源，下載會變快。
