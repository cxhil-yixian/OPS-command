OPS-command · Windows 篇

Windows 新手指南

不用記指令、不用翻設定畫面，照著選單按英文字母和數字，就能處理 Windows 10 / 11 常見的管理工作。

1這是什麼

OPS-command 的 Windows 工具，是一個用 PowerShell 做的選單。你可以用它：

  • 換遠端桌面（RDP）的 Port：換錯了會自動還原，不會把自己關在門外。
  • 查電腦為什麼自己重開機、藍畫面、誰登入過：用「症狀」找，不用懂事件代碼。
  • 解決遠端桌面連不上的常見錯誤。
  • 暫停 Windows 更新、校正時間、開關防火牆 Port、管理帳號。

會改設定的功能都會先說明接下來要改什麼，等你輸入 Y 才動手。看不懂時輸入 N 或直接按 Enter，什麼都不會改。

2開始之前

你需要

  • 一台 Windows 10 或 Windows 11 電腦。
  • 能連上網路（要從 GitHub 下載工具）。
  • 不需要先用系統管理員身分開啟。要改設定時，工具會問你要不要提權，答 Y 後跳出「使用者帳戶控制」視窗，按「是」就好。

支援哪些版本

Windows 版本能不能用
Windows 10 / 11 專業版、企業版✅ 可以
Windows 10 / 11 家用版⚠️ 大部分可以，但遠端桌面相關功能不能用（家用版本身就不能被遠端桌面連入）
Windows 7 / 8 及更舊❌ 不支援

不知道自己是哪個版本？按 Win + R，輸入 winver，按 Enter。

⚠️ 第一次用請先在測試機試

這個工具目前只有少數功能在真的電腦上測過。用在重要的電腦之前，先找一台不重要的試一次。換遠端桌面 Port 尤其要先試。

3三步驟開始

  1. 打開 PowerShell

    在「開始」按鈕上按右鍵，選「Windows PowerShell」（Windows 11 是「終端機」）。用一般身分開就可以。

  2. 複製下面兩行，貼上，按 Enter 
    [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12
irm https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/WINDOWS/ops-win.ps1 | iex

    在 PowerShell 視窗裡按滑鼠右鍵就是貼上。第一行是讓舊版 PowerShell 能連上 GitHub，不要省略。

  3. 看到選單，第一次先按 S 再按 Enter

    S 是「檢查現況」，只看不改，會列出這台電腦目前的遠端桌面 Port、Windows 更新、帳號鎖定等設定。

操作方式都一樣：輸入選項前面的英文字母或數字，按 Enter。大小寫都可以。子選單裡按 0 回到上一層，主選單按 0 離開。

下次要再用，重新貼一次第 2 步那兩行就好，每次都會下載最新版。

不方便用指令的話，也可以從 GitHub 下載整個 WINDOWS 資料夾，雙擊裡面的 Win_Admin_Tool.bat，進去之後完全一樣。

4主選單一覽

打開後會看到這個畫面：

============================================================
        Windows 10 / 11  系統管理工具  (分類選單)
        目前權限: 一般使用者 (修改功能會要求提權)
============================================================
  A. 遠端桌面 (RDP)     - 換 Port / 確認 / 還原 / 多開 / CredSSP / 登入紀錄
  B. 帳號與安全         - 鎖定 / Administrator / 改密碼
  C. 系統與更新         - Windows 更新 / Store / 時間時區
  D. 網路與防火牆       - Ping / Port / 批量加 IP
  E. 虛擬化 (Hyper-V)   - 與 VMware 切換 / 啟用停用
  F. 磁碟管理           - diskpart 視覺化
  S. 檢查現況           - 驗證設定 (免管理員)
  L. 事件檢視器         - 依症狀查事件紀錄 (免管理員)
  0. 離開
============================================================
請輸入代號 (A-F / L / S / 0):
按鍵用白話說會改設定嗎
S看這台電腦目前的設定（不確定時就按它）不會
L查事件紀錄：為什麼重開機、藍畫面、誰登入過不會
A遠端桌面：換 Port、修驗證錯誤、看登入紀錄會
B帳號：解除鎖定、啟用 Administrator、改密碼會
C系統：暫停 / 恢復 Windows 更新、校正時間會
D網路：開關 Ping、開關防火牆 Port、一次加很多個 IP會
EHyper-V 和 VMware 互相切換會（要重開機）
F磁碟：看磁碟狀況、改代號、格式化會（格式化會清掉資料）

5使用案例

每個案例都寫了「什麼時候用」和「按哪些鍵」。主選單 → A → 1 的意思是：先在主選單輸入 A，進去後再輸入 1，每次都按 Enter。

案例 A：看看這台電腦現在的設定

什麼時候用：接手一台不熟的電腦，或改完設定想確認有沒有生效。

  1. 主選單輸入 S。
  2. 畫面會列出遠端桌面 Port、Windows 更新狀態、帳號鎖定、能不能被 ping，以及目前有哪些 Port 正在使用。看完按 Enter 回主選單。

這個功能只看不改，一般身分就能用，可以放心按。

案例 B：把遠端桌面從 3389 換到其他 Port

什麼時候用：遠端桌面直接開在網路上，每天都有大量機器人在猜密碼。換成別的號碼能擋掉大部分。

⛔ 開始前一定要確認這兩件事

1. 換 Port 時，你現在的遠端桌面連線一定會斷。如果新 Port 連不上，要等 10 分鐘自動還原。最好有主控台（雲端後台的網頁畫面、或能走到電腦前面）可以救。

2. 雲端主機要先到雲端後台的「安全群組」放行新 Port，否則換完一定連不進來。

  1. 主選單 → A → 1。工具會問要不要提權，輸入 Y，在跳出的視窗按「是」，再到新視窗重新走一次 A → 1。
  2. 輸入新的 Port，例如 53389（建議在 10000 – 65535 之間挑一個）。
  3. 問「看門狗時限幾分鐘」時直接按 Enter（10 分鐘）。
  4. 畫面會列出接下來要做的事，確認後輸入 Y。
  5. 問「現在重啟 TermService?」時輸入 Y。這時連線會斷掉，是正常的。
  6. 在你自己的電腦打開「遠端桌面連線」，電腦欄位輸入 IP:新Port，例如 203.0.113.5:53389，重新連進去。
  7. 連得上 → 打開工具，主選單 → A → 2（確認新 Port 可用），輸入 Y。問要不要移除舊 Port 的規則時也輸入 Y。完成！
    連不上 → 什麼都不用做，10 分鐘後會自動還原成 3389，再用原本的方式連回去就好。

為什麼不會被鎖在門外？工具會先建一個「看門狗」排程。10 分鐘內沒有到 A → 2 確認，系統就會自動把 Port 改回原樣，就算你已經登出、斷線也一樣。

案例 C：遠端桌面出現「發生驗證錯誤」

什麼時候用：連遠端桌面時跳出「發生驗證錯誤。要求的函數不受支援」，訊息裡提到 CredSSP 加密 Oracle 修復。

  1. 在發起連線的那台電腦（你自己的電腦）打開工具。
  2. 主選單 → A → 5 → 1，看完警告後輸入 Y。
  3. 再連一次遠端桌面。

這是把安全檢查放寬，讓你先連得上。根本的解法是兩邊電腦都裝好 Windows 更新。更新完之後，回到 A → 5 → 2 還原。

案例 D：電腦自己重開機、藍畫面，想知道原因

什麼時候用：早上發現電腦重開過、程式一直當掉，或想知道誰登入過這台電腦。

  1. 主選單輸入 L（事件檢視器）。
  2. 選符合的症狀：
    按鍵症狀
    1電腦自己關機或重開機（還會寫出是哪個程式要求的）
    2藍畫面、硬體錯誤
    3硬碟有問題
    4服務啟動失敗，或設定被人改掉
    5程式當掉、沒有回應
    6誰登入過、密碼打錯、帳號被鎖（要提權）
    7Windows 更新失敗
  3. 畫面會列出最近 7 天的紀錄。輸入紀錄前面的編號可以看詳細內容，T 可以改成看 24 小時或 30 天，E 可以存成 Excel 打得開的檔案（放在桌面）。

這裡只看不改，可以放心用。

案例 E：帳號一直因為密碼打錯被鎖住

什麼時候用：登入時常常出現「帳戶已被鎖定」。

已經被鎖住的帳號，等鎖定時間過了會自動解開（Windows 預設通常是 10 分鐘），先等一下再登入。

如果三不五時就被鎖，可以讓 Windows 不再因為打錯密碼而鎖帳號：

  1. 主選單 → B → 1（解除帳號密碼鎖定），看完警告後輸入 Y。
  2. 問題解決之後，一定要把保護開回來。用系統管理員身分開 PowerShell，輸入： 
    net accounts /lockoutthreshold:5

關掉鎖定等於「密碼可以無限次亂猜」。一直被鎖，通常代表有人正在猜你的密碼，關掉鎖定只會讓他更好猜。根本的解法是只讓自己的 IP 連進來（用雲端的安全群組或防火牆限制來源），或換遠端桌面 Port（案例 B）。

案例 F：暫時不想讓 Windows 自動更新

什麼時候用：正在跑重要的工作，不想被自動更新重開機打斷。

  1. 暫停：主選單 → C → 1，輸入 Y。
  2. 恢復：主選單 → C → 2。

暫停更新會讓電腦收不到安全修補，忙完記得恢復。畫面如果說要重新開機才會生效，就重開機後再做一次。

案例 G：時間或時區不對

什麼時候用：右下角的時間差了幾分鐘，或差了好幾個小時。

  1. 主選單 → C → 4。
  2. 選要做的事：
    • 時間差幾分鐘 → 1（立即同步網路時間）。
    • 差了好幾個小時（時區錯）→ 3（設為台北 UTC+8），其他時區選 4 用關鍵字搜尋，例如 Tokyo。

案例 H：開放防火牆 Port、讓別人能 ping 到

什麼時候用：架了網站或服務，別人連不進來；或想讓監控系統能 ping 這台電腦。

想做什麼按哪裡
開放一個 Port主選單 → D → 2 → 1，輸入 Port，再選 TCP / UDP / 兩者
查某個 Port 有沒有程式在用主選單 → D → 2 → 2
關閉之前開的 Port主選單 → D → 2 → 3
允許 / 拒絕被 ping主選單 → D → 1

「關閉 Port」只會刪掉這個工具建立的規則，不會動到其他程式自己建的規則。雲端主機記得也要到安全群組放行。

其他功能

想做什麼按哪裡注意
啟用 / 停用內建的 Administrator 帳號B → 2啟用後記得設一個強密碼
改某個帳號的密碼B → 3—
看誰用遠端桌面登入過A → 6—
讓同一個帳號可以開兩個遠端桌面A → 4專業版仍然只能同時一個人連；家用版不能用
Microsoft Store 在背景一直吃資源C → 3 → 1關掉 Store 自動更新
裝了 VMware 開不了虛擬機E → 3切成 VMware 優先，要重開機
一張網卡加很多個 IPD → 3設錯可能斷網，遠端操作要小心
看磁碟用了多少F → 1只看不改
⛔ 磁碟管理的格式化和清除會永久刪掉資料

F → 3（格式化）和 F → 4（清除整顆磁碟）沒有辦法復原。工具會要你重複輸入好幾次確認，但只要輸入錯一個字母，資料就沒了。不確定的話不要碰。

6出問題怎麼辦

貼上指令後出現「無法建立 SSL/TLS 通道」

第一行沒有一起貼到。兩行要一起複製、一起貼上。

出現「因為這個系統上已停用指令碼執行」

改用另一種方式：從 GitHub 下載 WINDOWS 資料夾，雙擊 Win_Admin_Tool.bat。

畫面是亂碼

關掉視窗重新開一個 PowerShell 再試。還是亂碼的話，改用雙擊 Win_Admin_Tool.bat 的方式。

按了 Y 要提權，視窗閃一下就不見

先關掉所有 PowerShell 視窗，改成在「開始」按鈕上按右鍵，選「Windows PowerShell (系統管理員)」，再貼一次開始的兩行指令。

換了遠端桌面 Port，新 Port 連不進來

  • 先確認雲端後台的「安全群組」有沒有放行新的 Port。
  • 什麼都不用做，10 分鐘後會自動還原成原本的 Port。
  • 有主控台的話，也可以從主控台進去，主選單 → A → 3 立刻還原。

不知道哪裡出了問題

按 S 看現況，或按 L 查事件紀錄。這兩個都只看不改。

看到不懂的問題，不知道該不該按 Y

輸入 N 或直接按 Enter 就好。沒有輸入 Y，什麼都不會改。

7四條安全守則

  1. 換遠端桌面 Port 之前，先準備好主控台。連線一定會斷，主控台是你的退路。
  2. 雲端主機記得同時改安全群組。電腦裡的防火牆放行了，外面不一定進得來。
  3. 磁碟的格式化和清除，不確定就不要碰。
  4. 看不懂就不要按 Y。先按 S 看現況，或問懂的人。

8名詞小辭典

遠端桌面（RDP）
從另一台電腦連進來操作這台電腦的功能。
Port
電腦上的「門牌號碼」。遠端桌面預設走 3389 號門。
PowerShell
Windows 內建的指令視窗，這個工具就是在裡面執行。
系統管理員 / 提權
改系統設定需要的權限。「提權」就是從一般身分換成系統管理員身分。
使用者帳戶控制（UAC）
要提權時跳出來、問你「是否允許變更」的那個視窗。
防火牆
決定哪些連線可以進出這台電腦的守門員。
安全群組
雲端主機在雲端後台的防火牆，跟電腦裡的防火牆是兩回事，兩邊都要放行。
主控台
不透過網路、直接操作電腦畫面的方式，例如雲端後台的網頁畫面，或走到電腦前面。
看門狗
換 Port 時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。
事件紀錄
Windows 自動寫下的系統日記，記錄了開關機、錯誤、登入等事情。
