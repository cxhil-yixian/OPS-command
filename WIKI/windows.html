OPS-command · Windows 篇

Windows 新手指南

不用記指令、不用翻設定畫面，在圖形面板上點一點，就能處理 Windows 10 / 11 常見的管理工作。

1這是什麼

OPS-command 的 Windows 工具，是一個圖形面板。你可以用它：

  • 換遠端桌面（RDP）的 Port：換錯了會自動還原，不會把自己關在門外。
  • 查電腦最近有沒有出狀況：打開就自動檢查，用燈號告訴你哪裡要注意、該怎麼做。
  • 擋掉一直猜密碼的人：同一個來源猜錯太多次就自動封鎖。
  • 一次裝好常用軟體：打勾就裝，下載來源由微軟官方的 winget 核對。
  • 暫停 Windows 更新、校正時間、開關防火牆 Port、管理帳號、開 SSH。

會改設定的按鈕，按下去會先跳出視窗說明接下來要改什麼，等你按「是」才動手。看不懂時按「否」，什麼都不會改。每次改了什麼也都會記在「操作記錄」裡。

2開始之前

你需要

  • 一台 Windows 10 或 Windows 11 電腦。
  • 能連上網路（要從 GitHub 下載工具）。
  • 不需要先用系統管理員身分開啟。按到要改設定的按鈕時，工具會問你要不要提權，按「是」後跳出「使用者帳戶控制」視窗，再按「是」就好。

支援哪些版本

Windows 版本能不能用
Windows 10 / 11 專業版、企業版✅ 可以
Windows 10 / 11 家用版⚠️ 大部分可以，但遠端桌面相關功能不能用（家用版本身就不能被遠端桌面連入）
Windows Server 2019 / 2022❔ 還沒測過
Windows 7 / 8 及更舊❌ 不支援

不知道自己是哪個版本？按 Win + R，輸入 winver，按 Enter。

用在重要的電腦之前，先找一台不重要的試一次。每個功能都在測試機上實際按過，但你的環境可能不一樣。換遠端桌面 Port 尤其要先試，而且要有主控台可以救。

3三步驟開始

  1. 打開 PowerShell

    在「開始」按鈕上按右鍵，選「Windows PowerShell」（Windows 11 是「終端機」）。用一般身分開就可以。

  2. 複製下面兩行，貼上，按 Enter 
    [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12
irm https://raw.githubusercontent.com/cxhil-yixian/OPS-command/main/WINDOWS/ops-win.ps1 | iex

    在 PowerShell 視窗裡按滑鼠右鍵就是貼上。第一行是讓舊版 PowerShell 能連上 GitHub，不要省略。下載完會先核對檔案有沒有被改過，看到「完成（SHA256 已核對）」就會跳出面板，PowerShell 視窗可以關掉。

  3. 面板出來後，先點左邊「檢查與紀錄」→「檢查系統現況」

    它只看不改，會列出這台電腦目前的遠端桌面 Port、Windows 更新、帳號鎖定等設定。

操作方式都一樣：點左邊的分類展開，再點功能，會開一個新視窗。視窗上方「目前狀態」是這台電腦現在的實際設定，下面是按鈕，最下面黑色區域是執行結果。

下次要再用，重新貼一次第 ② 步那兩行就好，每次都會下載最新版。有新版時，面板上方也會用黃字提醒你。

不方便用指令的話，也可以從 GitHub 下載整個 WINDOWS 資料夾，雙擊裡面的 Win_Admin_Tool.bat，進去之後完全一樣。

5使用案例

每個案例都寫了「什麼時候用」和「點哪裡」。遠端桌面 RDP → 更換 RDP Port 的意思是：先點左邊的「遠端桌面 RDP」展開，再點「更換 RDP Port」。

案例 A：看看這台電腦現在的設定

什麼時候用：接手一台不熟的電腦，或改完設定想確認有沒有生效。

  1. 檢查與紀錄 → 檢查系統現況。
  2. 視窗會列出遠端桌面 Port、Windows 更新狀態、帳號鎖定、能不能被 ping，以及目前有哪些 Port 正在使用。
  3. 要留存或傳給別人看，按「匯出成文字檔」。預設存在工具的資料夾（%LOCALAPPDATA%\OPS-command），存檔視窗裡也可以改存到桌面。

這個功能只看不改，一般身分就能用，可以放心按。

案例 B：把遠端桌面從 3389 換到其他 Port

什麼時候用：遠端桌面直接開在網路上，每天都有大量機器人在猜密碼。換成別的號碼能擋掉大部分。

開始前一定要確認這兩件事：

1. 換 Port 時，你現在的遠端桌面連線一定會斷。如果新 Port 連不上，要等看門狗時間到才會自動還原。最好有主控台（雲端後台的網頁畫面、或能走到電腦前面）可以救。

2. 雲端主機要先到雲端後台的「安全群組」放行新 Port，否則換完一定連不進來。

  1. 遠端桌面 RDP → 更換 RDP Port。
  2. 「新的 Port」填新的號碼，例如 53389（建議在 10000 – 65535 之間挑一個）；「看門狗時限」維持 10 分鐘。
  3. 按「更換 Port」，看完說明按「是」。
  4. 問「現在重啟遠端桌面服務嗎？」時按「是」。這時連線會斷掉，是正常的。
  5. 在你自己的電腦打開「遠端桌面連線」，電腦欄位輸入 IP:新Port，例如 203.0.113.5:53389，重新連進去。
    • 連得上 → 剛才的視窗還開著，按「確認新 Port 可用」→「是」。問要不要移除舊 Port 的規則時也按「是」。完成！
    • 連不上 → 什麼都不用做，時間到會自動改回原本的 Port，再用原本的方式連回去就好。

為什麼不會被鎖在門外？工具會先建一個「看門狗」排程。時限內沒有按「確認新 Port 可用」，系統就會自動把 Port 改回原樣，就算你已經登出、斷線、面板關掉也一樣。

案例 C：遠端桌面出現「發生驗證錯誤」

什麼時候用：連遠端桌面時跳出「發生驗證錯誤。要求的函數不受支援」，訊息裡提到 CredSSP 加密 Oracle 修復。

  1. 在發起連線的那台電腦（你自己的電腦）打開工具。
  2. 遠端桌面 RDP → CredSSP 加密預示修復，按「設為『易受攻擊』」，看完警告按「是」。
  3. 重新開機後再連一次遠端桌面。

這是把安全檢查放寬，讓你先連得上。根本的解法是兩邊電腦都裝好 Windows 更新。更新完之後，回到同一個視窗按「還原為『尚未設定』」。

案例 D：電腦自己重開機、藍畫面，想知道原因

什麼時候用：早上發現電腦重開過、程式一直當掉，或想知道誰登入過這台電腦。

  1. 檢查與紀錄 → 事件檢視器。打開就會自動檢查最近 7 天，大約幾秒鐘。
  2. 看卡片的顏色：
    卡片意思
    ✔ 綠字「沒有異常」這一類沒問題
    ⚠ 黃底「N 筆需要注意」點進去看
    灰字「需要管理員權限才看得到」「登入與帳號」要提權才能看，點一下會問你要不要提權
  3. 點黃色卡片，清單裡「這代表什麼」和「建議怎麼做」會用白話說明，需要注意的排在最前面。
  4. 想看更早的紀錄，把上方「檢查範圍」改成「最近 30 天」。要給懂的人看，按「匯出 CSV」。

這裡只看不改，可以放心用。

案例 E：一直有人在猜遠端桌面的密碼

什麼時候用：登入時常常出現「帳戶已被鎖定」，或事件檢視器「登入與帳號」一直有登入失敗。

已經被鎖住的帳號，等鎖定時間過了會自動解開（Windows 預設通常是 10 分鐘），先等一下再登入。

一直被鎖，通常代表有人正在猜你的密碼。比起關掉帳號鎖定，更好的做法是把猜密碼的來源擋掉：

  1. 帳號與安全 → RDP 暴力破解自動封鎖。
  2. 先按「試算（不封鎖）」看看目前的設定會擋到誰。
  3. 確認「白名單」裡有你自己連進來的 IP（工具會自動加上目前連進來的來源）。
  4. 按「啟用／套用設定」。跳出的視窗會列出白名單，逐一看過，有不認得的 IP 就先按「否」，把它從白名單拿掉再啟用。
  5. 之後同一個 IP 在 10 分鐘內猜錯 5 次，就會被擋 60 分鐘（數字都可以改）。擋錯人時用「解封指定 IP」。

不要關掉帳號鎖定。關掉等於「密碼可以無限次亂猜」。帳號與安全 → 帳號鎖定防護 建議維持 5–10 次。

案例 F：暫時不想讓 Windows 自動更新

什麼時候用：正在跑重要的工作，不想被自動更新重開機打斷。

  1. 暫停：系統與更新 → Windows 更新，按「停止 Windows 更新」→「是」。
  2. 恢復：同一個視窗按「還原 Windows 更新」，會照暫停前的設定恢復。

暫停更新會讓電腦收不到安全修補，忙完記得恢復。畫面如果說「被系統改回來了」，重新開機後再按一次停止。

案例 G：時間或時區不對

什麼時候用：右下角的時間差了幾分鐘，或差了好幾個小時。

  1. 系統與更新 → 時間與時區。
  2. 時間差幾分鐘 → 按「立即校時」。
  3. 差了好幾個小時（時區錯）→ 在「時區」下拉選單選對的時區（台灣是 (UTC+08:00) 台北），按「套用時區」。

案例 H：開放防火牆 Port、讓別人能 ping 到

什麼時候用：架了網站或服務，別人連不進來；或想讓監控系統能 ping 這台電腦。

想做什麼點哪裡
開放、查詢、關閉一個 Port網路與防火牆 → 防火牆 Port 管理
允許 / 拒絕被 ping網路與防火牆 → Ping (ICMP) 設定

「關閉」只會刪掉這個工具建立的規則，不會動到其他程式自己建的規則。雲端主機記得也要到安全群組放行。

案例 I：一次裝好常用軟體

什麼時候用：剛拿到一台新電腦，要裝 7-Zip、Notepad++、Chrome 這些常用工具。

  1. 系統與更新 → 常用軟體安裝（winget）。等「狀態」那欄讀完，已經裝了的會顯示版本、不能勾。
  2. 在「安裝」欄勾選要裝的軟體，按「安裝勾選的軟體」→「是」。每個軟體可能要幾十秒到幾分鐘。
  3. 清單裡沒有的，到「搜尋其他軟體」分頁輸入名稱搜尋，選一個按「安裝選取的軟體」。

    安裝前會跳出發行者，確認是你要的那一家再按「是」。

如果顯示「找不到 winget」，照畫面說明到 Microsoft Store 安裝或更新「應用程式安裝程式」，再按「重新偵測」。Wireshark 裝完還要另外到 npcap.com 手動裝 Npcap 才抓得到封包。

案例 J：開 SSH，當遠端桌面的備用門

什麼時候用：只靠遠端桌面連這台電腦，萬一遠端桌面出問題就進不來了。多開一條 SSH 當備用。

  1. 網路與防火牆 → OpenSSH Server。
  2. 「SSH Port」填一個號碼（例如 22222），「預設殼層」選 PowerShell，按「啟用」→「是」。沒裝的話會自動安裝，要幾分鐘。
  3. 在你自己的電腦用 ssh 帳號@這台的IP -p 22222 測試看看。

SSH 已經在跑的時候不能換 Port（會讓 SSH 連線斷掉）。要換請先按「停用」再用新 Port 啟用。雲端主機一樣要到安全群組放行。

6出問題怎麼辦

貼上指令後出現「無法建立 SSL/TLS 通道」

第一行沒有一起貼到。兩行要一起複製、一起貼上。

出現「下載的檔案和 SHA256SUMS 對不上，拒絕執行」

下載到的檔案跟官方的不一樣，可能是網路被代理或公司的入口網頁攔截，也可能是 GitHub 剛更新、快取還沒同步。等幾分鐘再試；還是不行就換個網路，或從 GitHub 下載整個 WINDOWS 資料夾改用雙擊 Win_Admin_Tool.bat。

出現「因為這個系統上已停用指令碼執行」

改用另一種方式：從 GitHub 下載 WINDOWS 資料夾，雙擊 Win_Admin_Tool.bat。

按了要提權，按「是」之後沒反應

舊的面板會關掉，新的系統管理員面板會在幾秒後出現。如果都沒出現，關掉所有 PowerShell 視窗，改成在「開始」按鈕上按右鍵，選「Windows PowerShell (系統管理員)」，再貼一次開始的兩行指令。

換了遠端桌面 Port，新 Port 連不進來

  • 先確認雲端後台的「安全群組」有沒有放行新的 Port。
  • 什麼都不用做，看門狗時間到會自動還原成原本的 Port。
  • 有主控台的話，也可以從主控台進去，在「更換 RDP Port」視窗按「立即還原」。

跳出錯誤訊息

訊息裡會寫詳細內容存在哪個檔案（%LOCALAPPDATA%\OPS-command\error.log），把這個檔案給懂的人看。「檢查與紀錄 → 操作記錄」視窗裡按「開啟資料夾」，就能直接打開這個資料夾。

不知道哪裡出了問題

先看檢查與紀錄裡的「檢查系統現況」和「事件檢視器」，這兩個都只看不改。

看到不懂的問題，不知道該不該按「是」

按「否」就好。沒有按「是」，什麼都不會改。

7四條安全守則

  1. 換遠端桌面 Port 之前，先準備好主控台。連線一定會斷，主控台是你的退路。
  2. 雲端主機記得同時改安全群組。電腦裡的防火牆放行了，外面不一定進得來。
  3. 磁碟的格式化和清除，不確定就不要碰。
  4. 看不懂就按「否」。先看「檢查系統現況」，或問懂的人。

8名詞小辭典

遠端桌面（RDP）
從另一台電腦連進來操作這台電腦的功能。
Port
電腦上的「門牌號碼」。遠端桌面預設走 3389 號門。
PowerShell
Windows 內建的指令視窗，用來下載並打開這個工具。
系統管理員 / 提權
改系統設定需要的權限。「提權」就是從一般身分換成系統管理員身分。
使用者帳戶控制（UAC）
要提權時跳出來、問你「是否允許變更」的那個視窗。
防火牆
決定哪些連線可以進出這台電腦的守門員。
安全群組
雲端主機在雲端後台的防火牆，跟電腦裡的防火牆是兩回事，兩邊都要放行。
主控台
不透過網路、直接操作電腦畫面的方式，例如雲端後台的網頁畫面，或走到電腦前面。
看門狗
換 Port、改 IP 時的保險計時器。時間到了還沒確認，就自動把設定改回原樣。
事件紀錄
Windows 自動寫下的系統日記，記錄了開關機、錯誤、登入等事情。
白名單
永遠不會被封鎖的 IP 清單。一定要有你自己的 IP。
winget
微軟官方的軟體安裝工具，會核對下載的安裝檔沒有被改過。
SSH
用指令連進電腦的方式，可以當遠端桌面壞掉時的備用門。
SHA256
檔案的「指紋」。檔案只要改了一個字，指紋就會不一樣，用來確認下載的檔案沒被動過。
